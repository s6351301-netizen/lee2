TAIWAN CLAN VISUALIZATION DOCK

資料庫聯動：以實際遠端 JSON 宗親欄位驅動之 25 種 D3.js 核心圖表教學展廳

【1】直條圖 / 長條圖 / 直方圖 (Bar & Histogram Chart)
使用數據來源： 擷取 JSON 的 address 欄位，利用前 3 字計算台灣各地區宗親的人口分布總數（次數密度）。
技術簡介： 這是最基礎的數據分布圖。利用 d3.scaleBand() 排列地區 X 軸，d3.scaleLinear() 對應人數 Y 軸。透過 transition() 實現科技感十足的動態增長效果。
【2】橫條圖 (Horizontal Bar Chart)
使用數據來源： 擷取 JSON 前 10 筆宗親的 name 與其在資料庫中的 index（經乘算放大作為隨機資產權重指標）。
技術簡介： 橫條圖將 X 軸與 Y 軸的刻度屬性對調。極度適合用來展示名稱較長（如同本資料庫中完整的宗親姓名）的排列名次對比。
【3】折線圖 / 橫式折線圖 (Line Chart)
使用數據來源： 將 JSON 內的宗親依序排開，利用各節點生成的序列作為時間流動軸，映射出虛擬的宗親聯絡活躍度演變。
技術簡介： 使用 d3.line() 產生器，將離散的宗親數據點串接成一條連續的科技光軌折線。
【4】面積圖 (Area Chart)
使用數據來源： 同樣追蹤宗親序列，但將折線下方填滿半透明的螢光漸層色塊。
技術簡介： d3.area() 必須同時設定 y0（底部邊界線）與 y1（頂部數據線），適合用來展示宗親會累積資金或總人口結構的量體感。
【5】圓餅圖 / 環狀圖 (Pie & Donut Chart)
使用數據來源： 統計 JSON 陣列中所有宗親的 job（職業）分佈比例，算出各行業佔比。
技術簡介： 透過 d3.pie() 計算出每種行業應佔據的圓周角度，再利用 d3.arc() 渲染。調整 innerRadius 大於 0 即可一秒從圓餅圖切換成高科技質感的環狀圖。
【6】散佈圖 / 氣泡圖 (Scatter & Bubble Plot)
使用數據來源： 交叉搭配：X 軸為宗親名字的字數長度，Y 軸為其地區代碼，圓形大小（氣泡）代表模擬的家族核心影響力權重。
技術簡介： 每個宗親在平面中都是一個 circle。當我們引入第三個維度資料去動態控制半徑 r 的大小時，散佈圖即演變成氣泡圖。
【7】樹狀圖 / 族譜圖 (Tree Hierarchy Layout)
使用數據來源： 將 JSON 中的 address 縣市作為大分類，底下的 name 宗親姓名作為子節點，組織成嚴格的父子繼承結構。
技術簡介： 教學族譜的核心！利用 d3.hierarchy() 將扁平的 JSON 轉換為階層樹，並使用 d3.tree() 自動計算最優排版連線座標。
【8】力導向圖 / 網路關係圖 (Force-Directed Network)
使用數據來源： 取出前 35 筆宗親 name 作為關係網節點，並根據其是否處於同一個 job 行業別，隨機建立起橫向社交網絡連線。
技術簡介： 最能發揮 D3 動態靈魂的圖表。d3.forceSimulation() 動態模擬物理界粒子，節點間會排斥、連線間會牽引，產生彈跳尋找平衡的過渡動畫。
【9】地理地圖 / 疊加氣泡圖 (Geomap Overlay)
使用數據來源： 讀取各宗親的 address 所屬台灣縣市，結合台灣三大核心地理座標，在對應座標上疊加該區宗親數量的氣泡。
技術簡介： 使用 d3.geoMercator() 麥卡托投影法將經緯度轉換為網頁像素，並在其上利用 .append("circle") 達成數據疊加。
【10】樹狀矩陣圖 / 桑基圖 (Treemap & Sankey Diagram)
使用數據來源： 計算從「各地區縣市 (address)」流向「各行業類別 (job)」的實際宗親總人數權重流向。
技術簡介： 引入 d3-sankey 擴充套件，自動計算左右節點高度與中間連接帶（Links）的寬度，完美呈現數據的「流動感」與比例分布。
【11】弦圖 (Chord Diagram)
使用數據來源： 統計前三大縣市（台北、台中、高雄）宗親彼此之間交叉隨機搭配的商務往來次數，建立雙向矩陣。
技術簡介： d3.chord() 將複雜的多對多關聯關係轉化為圓環內部縱橫交錯的「弦帶」，極富數學幾何之美。
【12】沃羅諾伊圖 / 泰森多邊形 (Voronoi & Tessellation)
使用數據來源： 讀取每位宗親生成的虛擬位置座標，在平面空間中為每位宗親切分出其「最鄰近支配勢力範圍」。
技術簡介： 依靠 d3.Delaunay 演算法。它會根據平面散點，自動計算出由無數個多邊形細胞（Cells）組成的科技感網絡面板。
【13】旭日圖 (Sunburst Hierarchical Chart)
使用數據來源： 提取 address(內圈縣市大類) $\rightarrow$ job(中圈職業中類) $\rightarrow$ name(外圈個別宗親姓名) 的多層級階層鏈結。
技術簡介： 旭日圖是樹狀層級結構的圓形投影變體。利用 d3.partition() 將圓周角分配給各階層節點。
【14】雷達圖 / 蜘蛛網圖 / 蜂巢圖 (Radar & Honeycomb Overview)
使用數據來源： 隨機抓取一組核心宗親，評估其在資料庫中關聯出的 5 項維度指標（人脈、聲望、資歷、地區權重、活躍度）。
技術簡介： 運用三角函數 $x = r \cdot \cos(\theta), y = r \cdot \sin(\theta)$，將多維度非線性數據拉到同一個放射狀的網格中繪製閉合多邊形。
